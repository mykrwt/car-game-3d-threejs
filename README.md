# Coin Rush 3D

A small 3D driving game built with Three.js. Drive around the ring road, collect all 20 coins, and beat the 60 second clock.

## Controls

- Desktop: Arrow keys or WASD to drive and steer, Space or S to brake and reverse, R to restart.
- Phone or tablet: on-screen Left, Right, Brake and Gas buttons.

## Run it

ES modules need to be served over http. For example:

    npx serve .

Or enable GitHub Pages on the main branch (Settings, Pages) and open the published URL.

## Files

- index.html: page, HUD, overlay and touch controls
- main.js: scene, car physics, coins, camera and game loop
